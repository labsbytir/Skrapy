# Skrapy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port GoNewsk into fresh `labsbytir/Skrapy` repo as the Skrapy Wolfi image and ship it to GHCR.

**Architecture:** Single Go binary `skrapy` + Lightpanda sidecar in one Wolfi image; file FIFO queue, 1,000-link zip batches, S3 multipart via s5cmd (rclone fallback); token-authed API; Bubble Tea-style TUI extended from `metrics.TUI` with tir palette.

**Tech Stack:** Go 1.26, chromedp/CDP, Lightpanda 1.0.4, Wolfi apko/melange, python3, nodejs-24, s5cmd + rclone, plotext, btop.

**Spec:** `docs/superpowers/specs/2026-11-21-skrapy-design.md`

## Global Constraints

- Wolfi base `https://packages.wolfi.dev/os`, nonroot `65532`, podman via `/opt/podman/bin/podman`.
- MIT `Copyright (c) 2026 tir labs inc.`, SPDX MIT, apko `org.opencontainers.image.licenses: MIT`.
- Secrets only via env (`PROXY_URLS`/`PROXY_*`, `API_TOKEN`, `AWS_*`/`S3_*`), never baked or committed.
- Batch hard cap: max 1,000 links per batch, `<job>-batch-<NNNN>.zip` containing `batch-<NNNN>.jsonl`; delete local after S3 OK.
- TUI colors 24-bit ANSI only: blue `38;2;37;110;255`, indigo bg `48;2;70;35;122`, emerald `38;2;61;220;151`, white `38;2;252;252;252`, fuchsia `38;2;255;73;92`; errors always pair color + status-code text.
- Zero-dep `█` 40-col bars are the default for storage + S3 %.

## Review Focus

- Maximal AI record with a page that has empty title/meta but rich form values — expect `title=""`, `forms[].inputs[].value` populated, no crash.
- Depth flag `0` (seeds only) — expect zero link-follow, one batch.
- `--obey-robots=false` vs `true` on a disallowed path — expect fetch vs skip with `error="robots"`.
- S3 outage mid-batch — expect retry 3x backoff then dead-letter in `state.json`, fetch pipeline keeps running.
- `RUN_CAP_MB` hit mid-job — expect pause with TUI notice, resume after upload frees space.
